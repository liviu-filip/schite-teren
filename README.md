# Schițe teren

Aplicație web simplă (PWA) pentru schițele din teren pe tabletă: pereți (linii drepte, cu aliniere la 90°), uși, geamuri și cote.
Merge offline după prima deschidere. Schițele stau doar pe tabletă (memoria browserului); butonul „Trimite” le dă ca PNG + JSON prin meniul de partajare (ex. în Google Drive).

Depozitul conține doar codul aplicației, fără nicio schiță sau date.
